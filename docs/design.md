
# Detectra — Web Application Interface Design

## Overview

This document provides the Figma design reference for Detectra, a computer vision-based animal detection and monitoring system.

## Figma Design

[View Detectra Design in Figma](https://www.figma.com/design/CNNQIPpuNQoz283NL0pyGe/Detectra?node-id=8-2)

## Main Screens

- **Dashboard:** Main navigation and analysis options.
- **Image Upload:** Upload or select images for detection.
- **Detection Results:** Display predictions, confidence scores, and human verification.
- **Camera Scan:** Capture and analyze images from a connected IP camera.

## Design Style

Minimalist, responsive interface using black, white, and neutral gray colors.

## Implementation

- **Frontend:** Next.js
- **Backend:** FastAPI
- **Design Tool:** Figma

The Figma file serves as the primary visual reference for frontend implementation.
